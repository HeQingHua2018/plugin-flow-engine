# 快速上手

## 概述
组件库包含了插件流程引擎的 React 组件，用于可视化展示流程与插件化执行效果。
提供以下组件：
- [动态表单](./DynamicConfigForm/index.md)
- [流程可视化组件](./FlowView/index.md)
- [规则编辑器](./RuleEditor/index.md)
- [表单控件注入器](./FormWidgetInjector.md)
- [插件 UI 注册器](./PluginUIRegistry.md)

## 安装
```bash
# 使用 npm
npm install @chloehe/logic-engine-ui

# 使用 yarn
yarn add @chloehe/logic-engine-ui

# 使用 pnpm
pnpm add @chloehe/logic-engine-ui
```
